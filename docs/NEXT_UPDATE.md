## v0.5.0范围（2026-10-12确认，2026-10-17授权发布）

- MIDI：选轨道/通道，同一起音默认最高音，可选最低音；保留起音，截短前音以容纳gap，末音也在轨道结尾前留gap。短于52ms则舍弃并保留后续起音；整体移调需主动应用，剩余超音域音折叠八度。忽略弯音/踏板/音色/SysEx效果，显示截短、舍弃、八度调整数量和移调量及可展开详情。
- 提示原文：MIDI 将尽力转换，效果可能与原曲不同，请先试听确认。
- 播放列表：批量TXT、曲名/BPM/gap/路径、排序/移除/列表保存、旧谱兼容。单击只预选；双击先停止再处理未保存提示，加载后不播放，取消后保持停止。
- 开始使用预选曲，无预选使用编辑器；当前曲使用编辑器最新内容。上一首/下一首以当前曲为基准，停止状态也会切换并开始。正常结束自动下一首，末尾停止，不循环；每次演奏均3秒倒计时。
- 手动切歌提示保存；自动切歌遇未保存修改停止。自动下一首跳过缺失/错误谱并记录路径和原因，运行异常不续播。本地试听只播当前编辑器一首，无倒计时。
- 全局开始/停止/上首/下首均可自定义；默认F6/F8/空/空，无单曲快捷键。
- 游戏中意外中断后继续发送按键属于预期行为，由用户自行停止，不新增修复。已有取消、失焦、迟到和按键释放保护保留。
- 最小实施边界：演奏/倒计时/试听期间可预选和双击切编辑；增删排序及列表文件操作在停止后进行。.hpl保存引用与元数据，不保存编辑器草稿或曲谱副本。切歌等待旧任务退出，停止取消整个连续播放及待切换请求。
- 暂停、管理员重启、动态BPM播放器继续暂缓。本次不改变TXT语法、MIDI导出和采样资源。

## v0.4.0 已发布范围（以下为历史记录）

### 单旋律 MIDI 导入

- 读取 .mid/.midi，转换成 HarmonicaPlayer 可编辑 TXT 谱面；复用现有试听、演奏和 MIDI 导出，不另建 MIDI 播放器。
- 用户选择轨道／通道，只接受严格单音；任何重叠（含轻微重叠）都不自动截短，不取最高音/最低音，不猜主旋律，不丢音。
- 默认不自动修改音符与时序。“确认后调整”作为后续扩展，本次不实现。
- 复用当前开发版 MIDI 音高映射（48～85 全部半音，包含最高do升半音）；提供整体移调建议、原始及移调后的覆盖率，由用户主动应用。仍有超范围音符时阻止导入。
- 读取原速度事件，保留实际时间；多 BPM 和小数 BPM 转成固定整数 BPM 下的自定义时值，不量化节奏。
- gap 由用户明确选择，不从 MIDI 猜测。转换必须补偿目标 gap，保留原起音、发声结束和所选轨道总时长；不足最小 gap/按住时长、无法保留末尾时间或超过谱面限制时阻止导入，指出具体音符与时间。
- 初版支持 Standard MIDI File Format 0 / 1 的 PPQ 计时；Format 2、SMPTE 和 MIDI 2.0 文件明确提示不支持。弯音、延音/保持踏板、SysEx 等不能还原的事件明确提示；打击乐通道不转换。
- 转换成功后进入现有编辑器，作为尚未保存的 TXT；保留未保存修改确认流程，不覆盖源 MIDI，不自动演奏。

### 短休止调度 bug 修复和报错改进

- 保留原曲谱、BPM、gap、12ms 按键准备、音序和时间计划；给休止独立的 50ms 调度容差，避免按几毫秒休止的四分之一判定超时。
- 发声音符保留原严重超时保护；失败后取消播放并尝试释放输入，避免补发积压音符。
- 调度超时时显示实际迟到和阈值、音符/休止序号、曲谱行列及片段、曲内时间；提供定位与针对性处理建议，不把超时一律归因为设备性能不足。
- 完成取消/释放后再显示错误对话框，并在主界面保留提示；过期回调不得覆盖新播放。

### 管理员权限／仅测试提示优化

- 每次启动“仅测试”都不勾选，不保存上次模式。
